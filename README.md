# Property Platform

A property listings platform for the South African market, for web and mobile.

- **Web:** Next.js (TypeScript)
- **Mobile:** React Native + Expo
- **Backend:** ASP.NET Core (C#) + PostgreSQL/PostGIS

See [docs/architecture.md](docs/architecture.md) for the full stack, integrations and repository layout.
